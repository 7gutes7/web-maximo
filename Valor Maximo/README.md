# Ecosistema Digital Valor Máximo

Este repositorio contiene el código fuente de la Single Page Application (SPA) para **Valor Máximo**, el "Tinder Inmobiliario" de alto rendimiento.

## Tecnologías Utilizadas
- **HTML5**: Estructura semántica.
- **CSS3 (Vanilla)**: Diseño moderno, responsive y de alto rendimiento utilizando Custom Properties, CSS Grid, Flexbox y efectos avanzados como *glassmorphism*.
- **JavaScript (Vanilla)**: Lógica de interacción, navegación suave (`smooth scroll`), animaciones y restauración de scroll al recargar.

## Características Principales
- **Hero Section (Buscador)**: Motor de búsqueda de precisión inmobiliaria con filtros interactivos.
- **Diferenciador**: Propuesta de valor con animaciones sutiles.
- **Casos de Éxito Quirúrgicos**: Grid responsivo de logos de clientes.
- **Catálogo Elite (El Match)**: Tarjetas de inmuebles con perfiles de riesgo y descripciones directas.
- **Customer Journey (The Pit Stop Sequence)**: Timeline de 5 pasos en modo oscuro.

## Instalación y Uso
Al ser un proyecto Vanilla (sin frameworks pesados de frontend), no requiere un proceso de construcción (`build`) complejo.

1. Clona este repositorio.
2. Abre el archivo `index.html` en cualquier navegador web moderno, o utiliza una extensión como **Live Server** en VS Code para tener recarga automática durante el desarrollo.

## Diseño
El diseño fue implementado respetando una estética de alta gama, equilibrando espacios en blanco (fondos off-white) con secciones oscuras (dark mode) y utilizando tipografías premium (*Inter* para cuerpo y *Playfair Display* para titulares).
